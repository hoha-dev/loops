# docs/reviews — Cross-review snapshots

> A recurring harness ritual (see LOOP.md): every milestone, one person/agent reads the whole docs chain crosswise with impartial eyes and leaves an **immutable** snapshot here.

## Conventions

- File name: `YYYY-MM-DD-<scope>.md` (e.g. `2026-01-15-po-review.md`).
- A report is a snapshot at review time, NOT a living doc — never go back and edit it.
- Decisions arising from a review → update the source doc (bump version/changelog) or add an ADR through the normal process.
- Template: [`../templates/review.md`](../templates/review.md).
